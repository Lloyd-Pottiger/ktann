# Use RaBitQ7 leaves with exact reranking

Production leaves use an absolute per-vector RaBitQ7 algorithm rather than a partition-centroid-relative one-bit codec. After metric preprocessing and one persisted index-seeded Givens rotation, each dimension is encoded as one sign bit plus six magnitude bits. Format v1 fixes the rotation as three ChaCha8-seeded Fisher-Yates pairing rounds with the fixed f32 coefficient `1/sqrt(2)`, so every process reproduces it. Least-squares rescaling uses the signed integer code (sign applied to magnitude), not the unsigned magnitude. Each Leaf Entry stores its vector-local f32 scale, exact u32 squared integer-code norm, and an upward-rounded f32 reconstruction-error bound. Persisting the integer-code norm makes L2 metadata exactly consistent with the stored scale. No partition quantization parameters exist. Consequently an unchanged entry can copy its versioned RaBitQ7 payload verbatim during split or merge even when the target centroid differs; only insert and a vector-changing upsert re-run preprocessing, rotation, and encoding. KTANN owns and versions the complete codec, rotation generator, and formulas.

Approximate distance and a reconstruction-error bound form a `[lower, upper]` interval for every candidate. Inner product and cosine use query norm times reconstruction error; L2 derives its bound from estimated distance and reconstruction error. Production v1 uses the scalar f64 kernel so the interval has no unaccounted f32/SIMD rounding term. A future optimized kernel is valid only after its proven rounding bound is included in the interval. Non-finite decoded state is Corruption; non-finite arithmetic derived from caller input is InvalidArgument. Rough selection retains the bounded top set plus interval-overlap candidates before original f32 vectors are batch-read and reranked with f64 accumulation; exact rerank ordering within the selected candidates remains distance then RecordId.

The routing pipeline first validates the caller vector, applies cosine normalization when needed while leaving L2 and inner-product vectors unnormalized, and then applies the seeded rotation before RaBitQ7 encoding. Query routing uses the identical preprocessing and rotation. Exact rerank always uses the stored unrotated original vector: cosine recomputes norm/dot in f64, rejects zero vectors, and L2 returns Euclidean distance after squared-distance ranking, while inner product exposes distance as negative dot product. Any non-finite original or derived value is rejected rather than clamped.

The versioned per-entry payload has a fixed 12-byte little-endian header—`scale: f32`, `code_norm_squared: u32`, and `reconstruction_error_upper: f32`—followed by `ceil(dimension / 8)` sign bits and `ceil(6 * dimension / 8)` six-bit magnitude data. Manifest dimension determines the exact payload length, so entries do not repeat dimension or component lengths. Both streams are LSB-first; unused padding must be zero. Codec version also fixes the initial `max_abs / 63` scale, nearest rounding with halfway cases away from zero, positive sign for zero magnitude, the f64 least-squares rescale against fixed integer codes, and the canonical all-zero encoding. Inner-product intervals may be negative. L2 clamps only rough distance and its lower endpoint to zero and requires a finite upper endpoint. Cosine approximate and exact values are not clamped to their theoretical range, so unexpected numeric behavior stays observable rather than hidden.
